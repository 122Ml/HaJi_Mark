- 教师导入 PDF、DOCX、PPTX、文本/Markdown、HTML、CSV，保留原件和来源；常规表格提取、中文印刷扫描 OCR、异常核对、原文追加修订。
- 学习资料按选中片段或完整原件发布；知识库独立维护概念、方法、规则、示例和误区，保留适用条件、原文引用、课程知识点及相关知识。AI 只提出候选，教师编辑、确认与归档。
- Go 内实现 pgvector 精确向量检索、中文分词全文检索和 RRF 融合。可靠原文可直接建索引，不依赖生成式提炼；学生只检索已发布资料和允许学习的公开确认知识。
- 百炼北京按量接口接通 Embedding、问答、知识提炼、独立标准起草及评阅草稿。标准不读取待评答案，评分绑定确认标准和冻结依据，正式反馈仍须教师确认、发布。
- 模型按服务端 profile 配置，教师选择可用模型；OpenAI 兼容 Embedding 协议可更换供应商，专有协议需适配。密钥只在服务端。联调共享 50 元保守记账预算，不能替代供应商账单。

## 2026-11-11 独立题库与固定标准

教师端“题库”独立于作业维护题目，支持手工录入、JSON候选导入、历史版本和停用。AI可按选定资料或知识生成题目、参考解答和标准草稿，也可单独分析题目或起草标准；不读取待评学生答案。教师分别确认题目、参考解答和标准后，作业才能选用。

作业固定题目版本、满分及标准版本，人工与AI评分都核对该绑定；改分值另建题目及匹配标准，新版不改变旧作业和正式结果。资料／知识详情可进入“据此出题”，评分保留逐点规则、出处和原文引用。AI候选必须主动载入编辑，过期生成条件不能覆盖当前编辑。

首版本地实现与边界见[题库方案](docs/research/question-bank-rubric-plan.md)，接口见[契约](docs/contracts.md)。2026-11-12已补整卷三题型拆分、来源引用影响清单、按关闭作业单题整组重评和服务端筛选分页。单个批次不跨多个作业；公网版本未随本轮更新。

## 开始运行

安装并启动 Docker Desktop（Linux containers），在仓库根执行：

```powershell
# 仅首次且没有 .env 时复制，避免覆盖本地配置
if (!(Test-Path .env)) { Copy-Item .env.example .env }
docker compose config --quiet
docker compose build
docker compose up -d
pwsh -File scripts/seed-s1.ps1
pwsh -File scripts/smoke.ps1
```

打开 [本地平台](http://127.0.0.1:18080)。账号密码在被忽略的 `.local/s1-accounts.json`：教师 `s1-teacher`、另一教师 `s1-teacher-other`、学生 `s1-student-a/b`，密码随机生成。重复种子不重置账号和业务数据。教师可新建课程、加入已有学生或开通学生账号、录入/审核资料和题目后发布。参考课程目录可在空课程导入，目录不附带假成绩或未经审核的资料。

停止执行 `docker compose down`，保留卷。AI 默认 `AI_ENABLED=false`，无需配置密钥。默认 Compose 只绑定本机，不直接用于公网。
