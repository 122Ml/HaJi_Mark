## 读图与事实边界

每张图底部列出源码或配置入口。教师关口用深色，AI 候选用橙色，持久数据用蓝色，系统处理用白色，外部边界用灰色；未实现能力用灰色虚框。箭头语义由图名、标签和说明确定：业务流程表示交接，DFD 表示数据流，ER 表示概念关联，物理表图表示 FK，时序图表示请求与返回，包图表示依赖。不能把不同图中的实线都解释成数据库外键。

- **资料与知识**：原文发布、直接索引、知识提炼是独立分支。资料发布与知识确认不能互相代替；来源许可和归档会限制未来检索，历史评分快照保留。
- **命题与评阅**：题目、参考解答、评分标准分别确认；作业固定确切版本。主观题 AI 只产生草稿，教师确认与发布是两个动作；客观测验按教师固定答案规则判分。
- **整组重评**：仅冻结所选关闭作业的一道题及每人最新正式提交，逐份确认后一个事务统一发布；任一冲突全组回滚。读端下次请求读取正式结果，没有在图中冒充主动推送。
- **诊断与干预**：现有的是正式评价证据汇总、学生规则路径、教师补学补练和人工复查。AI 共性错因诊断、自动个性补练、批量学生答案导入、问答持久历史、匿名代表答案沉淀与独立效果评测均保留未完成边界。
- **实现组织**：F19 按实际 Go 包、React 模块与运行入口画依赖，不虚构类继承或独立微服务。代码题按文本评阅，不执行学生代码。

Excel 中的阶段计划、WBS 与 T01–T24 不因图册完成而自动变成“已完成”。图纸渲染检查也不能替代功能验收、模型评测或教师审核。

## 数据库覆盖与依据

F14 主图按八个主题域汇总；三张分图合计覆盖 **41 张业务表、103 条物理外键**。结构来自本地 PostgreSQL 系统目录的只读快照，不查询业务行；`schema.json` 记录列可空性、约束和 00001–00012 迁移的 SHA256，生成时校验迁移未漂移。`schema-coverage.json` 保存表归属和跨分图别名，生成器断言全部 FK 恰好覆盖一次。

分图箭头从子表指向父表；`FK?` 表示至少一个子列可空，`FK!` 表示子列均非空。同一对表的多个 FK 合并箭头，列名仍逐项保留，因此箭头数不等于约束数。跨域父表仅重复定位，不重复统计。`topic_links` 未声明 PK，按实标注；`embedding_spaces` 的 `(id, dimensions)` 唯一键支撑复合外键。

`content_tags.object_id`、`content_decisions.object_id` 等多态引用，以及 `evidence`、`fragment_ids`、`related_ids` 等 JSON／数组引用不冒充物理 FK；相关资格与版本约束由业务代码校验。F02 的概念关联与 F14 的物理约束分别表达。

本轮直接采用同目录[五张高完成度参考图](../README.md)的视觉与业务细节：F06、F06-1、F07、F09-1 复用其学习资料、知识、题目标准和变更重评生成函数，补入图号与事实边界，原参考文件保持不变。其余图按同等信息密度展开。具体功能验证范围见[三模块实际验收](../../research/three-module-acceptance-2026-11-12.md)。

## 重新生成与检查

从仓库根目录重新生成：

```powershell
python -B docs/diagrams/atlas/generate.py
$env:NODE_PATH='C:/Users/23396/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules'
node docs/diagrams/atlas/render.cjs
python -B scripts/check_docs.py
```

Python 需要 Pillow 和微软雅黑字体；Node 需要 Playwright 与 Microsoft Edge。`NODE_PATH` 应按实际依赖位置调整。SVG 与 PNG 串行生成／渲染，普通重绘不访问模型、业务服务或生产数据库。

迁移变动后，应先在本地应用正确迁移，再执行 `python -B docs/diagrams/atlas/capture-schema.py` 刷新结构快照，检查表分组与新增约束后重新生成。该脚本只连接本地 Compose 的 PostgreSQL，不能用旧快照或扩白名单跳过结构差异。

`generate.py` 检查主图齐全、节点不重叠、连线不穿无关节点和表／FK 全量覆盖。`render.cjs` 检查 27 张图的实际文字边界、节点内文字重叠、边标签遮挡，以及图册切换、分图、下载链接、高亮、缩放和桌面／窄屏入口；结果写入 `render-report.json`。最终 PNG 还需逐张目视检查，避免几何检查通过但读图含义错误。
