# 课程工作台交互原型

打开 [index.html](index.html) 即可操作，HTML、CSS、JavaScript 均为本地文件，不依赖外部库。默认进入教师的资料工作区。设计依据为[前端业务链路审计](../../research/frontend-business-chain-audit-2026-11-18.md)。

这是用于评审排布与交互的独立原型，尚未接入真实业务页面。课程、师生、作答、评分、知识候选和助理回复均为示例；输入和更改仅保存在当前页面内存中，刷新重置。未调用模型、后台解析、检索、数据库或生产服务器。

## 可操作流程

- 课程内容：搜索与切换资料；导入 TXT / Markdown 或粘贴文本；选择原文片段；编辑新修订；修改和确认知识候选；在知识库查看来源快照；预览并显式发布学生可见文本。索引始终标为未连接。
- 作业与批阅：切换学生作答；修改逐点评分与反馈；保存草稿、确认评分、预览发布分别操作。学生视图只展示已发布的样例反馈，新作答与预置评分样例明确分开。
- 学情与干预：从示例失分证据打开任务表单，保留学生和知识点；选择已发布资料，核对期限与要求后本地下发；学生任务打开所选资料。不把阅读标记当作掌握，不冒充已收到新证据。
- 课程管理与交流：切换目录、成员和设置；保存本页课程名称；在原话题内回复。
- 学生视图：任务内进入阅读，保存笔记、标记阅读；练习先预览再提交。教师新修订在再次发布前，不改变学生已发布阅读文本。
- 上下文助理：随对象与原文片段切换，支持依据、当前角色操作记录、收起和展开。发送仅演示消息交互，回复标明未调用模型。
