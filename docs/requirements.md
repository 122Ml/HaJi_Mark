## 依据优先级

本轮用户反馈：老师要求完成学生端基础学习流程和教师端完整监控，再选方面深化。这覆盖旧稿“仅教师端”“平台其他模块未来接口”的排除边界；旧材料保留不原地重写。

教师第三课讲义 p1/3/7 要求 M1—M10 与至少两个 E 意向，p18—20 要求垂直切片且当轮不做不取消学期必做，p31 要求 Git、CI、数据模型和最小骨架。第二课原任务单“只探查一个模块、不要求整个平台”是阶段任务，不是学期范围授权。来源原件/提取文本见 sources。

以下 REQ 是本组功能编号，不是冒充教师原需求编号。M1—M4、M7 的逐项正式名称未在现有材料中找到，葛炫毅负责取得清单再逐一映射；当前仍承担对应学习/提问基础能力。

## 两条端到端验收

24条可验收用户故事及逐条来源见 [用户故事详表](stories.md)，满足第三课原任务单的数量要求；是否属于正式课程验收仍由教师核对。

学生：看到教师发布资料 → 学习/提问 → 完成作业或测验 → 记录原文 → 正式反馈 → 查看依据画像 → 接受推荐或教师任务 → 新学习与新作答。教师：维护课程/题目/标准 → 发布 → 看完成与提交 → 下钻证据 → 评分复核 → 安排干预 → 复查新结果。

一门课、一个章节、2—3个知识点、1道客观题和1道文本主观题即可用于首个验收。正式模块清单可能补充基础项，得到教师清单后做差距表；参考站全部高级菜单不自动成为必做。
