# 全景部分实现项收口

本轮只在本地补齐明确的能力与交互。业务语义存在分歧的扩展保留给下一轮讨论，不以改名或关闭入口宣称完成。原应用基线为`560de5e`，总图基线为`356bc85`。

## 本轮实现

| 范围 | 现在的行为 | 业务边界 |
| --- | --- | --- |
| 检索答疑 | 保存本人问题、回答及引用快照；历史分页、URL定位、刷新恢复；失败记录可核对、问题可带回输入框 | 同一请求号复用已保存结果，失败或未知请求不自动重发模型；历史不是多轮模型记忆 |
| 教师批量导入 | 选单题、上传或粘贴UTF-8 CSV、预览学生归属/重复行/次数、确认后整批写入；显示回执和来源 | 最多200份、512KiB；主观题/代码文本；仅本课程已发布且未截止作业；不建学生账号、不覆盖旧作答 |
| 导入证据 | 保存导入人、批次、源行、原始答案、哈希及新attempt；旧记录不变 | 活动明确记为教师导入，不能冒充学生下发后执行补练；未评分不生成成绩 |
| 规则学习路径 | 每个知识点展示当前可用的精炼知识，点击进入确切知识版本 | 复用后端确认/学习用途/学生可见/来源许可过滤；未增加模型排序或自动生成补练 |
| 班级评分缺口 | 按题目、标准和评分点统计正式失分人数；名单下钻到原句、反馈、原文和补学补练 | 只用每人每题有效正式结果；其他标准和无正式结果分别展示；不是AI错因诊断 |
| 助理历史 | 本人会话服务端搜索/分页；消息与执行记录按游标加载更早页；审批、步骤和附件随页读取 | 活跃运行及近期更新记录保留可操作；不扩大模型上下文或开放任意SQL；供应商token流未增加 |
| 助理只读工具 | 可读本人问答历史、指定问答和教师导入审计 | 重走原业务路由；读取作答/学习上下文后继续禁止本会话起草题目和标准 |

导入确认会重读名单、任务版本及作答次数；预览过期返回409，不偷换下一次attempt。校验失败整批不写入；网络重试复用同一请求号返回原批次。CSV中的换行、空格、转义引号保留在不可变答案内。

## 已确认规则

2026-11-17用户确认：逾期或已关闭的作业禁止新增补录，不增加填写原因、特殊权限或独立补录批次等例外。现有后端在预览及确认时均核对作业状态与截止时间，已经满足该规则。已成功导入批次的同请求号重放仍只返回原回执，不追加作答。
